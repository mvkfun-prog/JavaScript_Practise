# JavaScript_Practise

JavaScript practice exercises covering fundamentals, conditionals, loops,
functions, arrays, and objects.

## Lessons

- `JS_Basics.js` - variables, conditionals, FizzBuzz, functions, and score exercises.
- `Lesson6_Objects.js` - student objects, grades, the top student, class average,
  and adding a `passed` property to each student.

Run a lesson with Node.js:

```sh
node Lesson6_Objects.js
```
